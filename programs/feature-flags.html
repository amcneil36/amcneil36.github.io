    Choose Rollout Method

    Choose how you want to apply this change.

    🐦

    Canary Rollout

    RECOMMENDED

    Gradually roll out the change while monitoring health metrics.

    • ✓ Start with a small percentage of identifiers
    • ✓ Automatically increase traffic over time
    • ✓ Monitor health and metrics continuously
    • ✓ Automatically rollback if issues detected
    ⚡

    Emergency Bypass

    Immediately apply the change to all identifiers.

    • ✓ Skip canary checks and staged rollout
    • ✓ Change is immediate and global
    • ✓ Use for urgent fixes or critical situations
    • ✓ You can rollback manually if needed
